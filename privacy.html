Kto korzysta z aplikacji

Dziennik Zdrowia to aplikacja do użytku osobistego jednej osoby (autora). Nie jest udostępniana innym użytkownikom.

Jakie dane Google są używane

Aplikacja korzysta z Google Health API wyłącznie w trybie tylko do odczytu (zakresy googlehealth.sleep.readonly, googlehealth.health_metrics_and_measurements.readonly, googlehealth.activity_and_fitness.readonly) i tylko dla konta autora: sen i fazy snu, tętno i tętno spoczynkowe, zmienność rytmu serca (HRV), oddech, saturacja, temperatura skóry, kroki. Do zapisu wyników używa Dysku Google autora (zakres drive.file: tylko pliki utworzone przez aplikację).

Jak dane są przechowywane

Dane są zapisywane jako pliki JSON w folderze na prywatnym Dysku Google autora. Aplikacja nie ma własnego serwera ani bazy danych. Autor ogląda dane w prywatnym dashboardzie, który odczytuje te pliki za pomocą konektora Google Drive w serwisie claude.ai (Anthropic), działającego z uprawnieniami autora.

Udostępnianie

Dane nie są sprzedawane, nie są wykorzystywane do reklam ani udostępniane osobom trzecim. Nie są używane do trenowania modeli uczenia maszynowego przez autora aplikacji.

Usunięcie danych

Autor może w każdej chwili usunąć pliki z Dysku i cofnąć dostęp aplikacji na stronie myaccount.google.com/permissions.

Zgodność z zasadami Google

Korzystanie z danych otrzymanych z interfejsów API Google jest zgodne z Google API Services User Data Policy, w tym z wymogami ograniczonego użycia (Limited Use).

Summary (EN): Single-user personal app. Reads only the author's own Google Health data (read-only scopes) and stores it as JSON files in the author's private Google Drive (drive.file scope). No server, no database, no sharing or sale of data, no advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
