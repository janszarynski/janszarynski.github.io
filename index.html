Dziennik Zdrowia

Prywatna aplikacja do użytku osobistego · Personal, single-user app

Dziennik Zdrowia to osobisty dashboard zdrowotny jednej osoby. Raz na kilka godzin skrypt Google Apps Script na koncie autora pobiera wyłącznie dane autora z Google Health API (sen, tętno, HRV, oddech, saturacja, temperatura skóry, aktywność; tylko do odczytu) i zapisuje je jako pliki JSON na prywatnym Dysku Google autora. Autor ogląda je w prywatnym dashboardzie.

Aplikacja nie jest przeznaczona dla innych użytkowników, nie ma rejestracji ani logowania dla osób trzecich.

Dziennik Zdrowia (“Health Journal”) is a personal health dashboard used by a single person. A Google Apps Script on the author's account periodically reads only the author's own data from the Google Health API (read-only) and stores it as JSON files in the author's private Google Drive. It is not offered to other users.
